
# Qing Zhao | Portfolio DAW

## Descripción
Portfolio web personal creado para presentar mi perfil, mi formación en Desarrollo de Aplicaciones Web (DAW) y los proyectos que voy desarrollando durante mi aprendizaje.

El diseño busca combinar programación y creatividad mediante una interfaz visual, organizada y adaptable a distintos tamaños de pantalla.

## Tecnologías utilizadas
- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño visual, estilos y adaptación a diferentes pantallas.
- **JavaScript:** interactividad de la página.
- **Git y GitHub:** control de versiones y gestión del repositorio.
- **GitHub Pages:** publicación del portfolio.

## Contenido
- Presentación personal.
- Formación y habilidades técnicas.
- Proyectos de programación con enlaces a las demos y al código.
- Información de contacto y currículum.
